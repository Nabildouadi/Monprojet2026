UN SEUL PROJET, DEUX MODES DE FONCTIONNEMENT

  L'application choisit automatiquement son mode :

  * Sur un PC avec serveur  -> MODE NORMAL : PHP + MySQL
      Adresse http://... ou http://127.0.0.1:8080/index.html
      Toutes les donnees (profils, projets, notes, photos,
      parametres) sont enregistrees dans la base MySQL.

  * Depuis une cle USB ou un simple dossier (adresse file://)
      -> MODE PORTABLE : enregistrement dans le navigateur
      (localStorage), aucun serveur, aucune installation.

  Un badge en bas a droite indique le mode actif :
      bleu   = "Mode serveur (MySQL)"
      orange = "Mode portable"

  On peut forcer un mode avec l'adresse :
      index.html?mode=normal
      index.html?mode=portable

  Si le serveur PHP repond mal ou si MySQL est arrete en mode
  normal, l'application bascule automatiquement en mode portable
  pour ne jamais bloquer le travail (le badge change de couleur).

FICHE PROJET DYNAMIQUE (9 sections numerotees)

LOGOS 3D ANIMES
  Les deux logos (en-tete et page d'accueil) passent en relief 3D
  avec une animation de flottement, un reflet qui balaie l'image
  et un zoom au survol. L'animation s'arrete a l'impression et si
  Windows demande de reduire les animations.


================================================================
 1) MODE NORMAL : PHP + MYSQL (recommande sur PC)
================================================================

PREREQUIS
  - XAMPP (ou WAMP) installe, avec PHP 7.4 ou plus recent
  - MySQL / MariaDB demarre (bouton Start dans XAMPP)

LANCEMENT RAPIDE (recommande)
  Double-cliquez sur :  Lancer-Les-Projets.bat
  Ce lanceur choisit tout seul le bon mode :
    - PHP + MySQL detectes  -> MODE NORMAL
    - sinon                 -> MODE PORTABLE (sans installation)
  Il detecte PHP dans XAMPP, WAMP, Laragon, le dossier local
  ou le PATH, choisit un port libre (8080, puis 8081...)
  et ouvre le navigateur automatiquement.

ETAPE 1 - INSTALLER LA BASE
  Double-cliquez sur :  Installer-Base.bat
  Le navigateur s'ouvre sur install.php et affiche
  "Installation Reussie !".
  La base "insfp_projets" et toutes les tables sont creees.

  Equivalent manuel :
      http://localhost/votre-dossier/install.php

ETAPE 2 - LANCER L'APPLICATION
  Double-cliquez sur :  Lancer-Les-Projets.bat
  (ou directement sur Lancer-Version-Normale.bat)
  Le navigateur s'ouvre sur :
      http://127.0.0.1:8080/index.html
  Si le port 8080 est deja pris, le lanceur utilise 8081, 8082...
  L'adresse exacte est affichee dans la fenetre noire.
  Laissez la fenetre noire ouverte pendant l'utilisation
  (c'est le serveur PHP). Fermez-la pour arreter le serveur.

  Avec XAMPP, vous pouvez aussi copier tout le dossier dans
  C:\xampp\htdocs et ouvrir :
      http://localhost/NOM-DU-DOSSIER/index.html

================================================================
 2) MODE PORTABLE : CLE USB / SANS INSTALLATION
================================================================

DEUX FACONS D'UTILISER LE MODE PORTABLE

  a) Version tout-en-un (1 seul fichier, ideal cle USB) :
       dist\Les Projets des Stagiaires - Portable.html

     Pour la (re)generer apres une modification du code :
       - double-cliquez sur  build-portable.bat
         (necessite Node.js installe sur le PC de preparation)
       - ou lancez  Lancer-Version-Portable.bat  : il genere le
         fichier s'il n'existe pas, puis l'ouvre.

     Ce fichier contient le CSS, le JavaScript et les polices
     d'icones : il fonctionne par double-clic, sans Internet,
     sans PHP et sans MySQL. Copiez-le sur la cle USB.

  b) Le dossier complet ouvert directement :
       index.html
     ouvert par double-clic fonctionne aussi en mode portable
     (adresse file://). Pratique pour tester rapidement.

  IMPORTANT : en mode portable, les donnees sont stockees dans
  le navigateur de l'ordinateur utilise. Elles ne suivent pas la
  cle USB d'un PC a un autre. Pour transferer des donnees :
      - utilisez les boutons "Exporter (JSON)" / "Importer (JSON)"
        de l'application,
      - ou utilisez le mode normal MySQL sur un PC fixe.


================================================================
 3) OU SONT ENREGISTREES LES DONNEES ?
================================================================

  MODE NORMAL (MySQL) :
      profils stagiaires ........ table stagiaires
      specialites ............... table specialites
      fiches projets ............ table projets (+ data_json)
      membres, objectifs, etapes, materiel, photos, notes
                                  tables projet_*
      theme, logos, galerie, archive, textes
                                  table settings

  MODE PORTABLE (localStorage du navigateur) :
      ps_profiles, ps_specialites, ps_fiches_projets,
      ps_settings, ps_archive_projets, ps_logo_*, ps_galerie...

  Le meme code source (script.js) sert aux deux modes : chaque
  action passe par une seule fonction (apiCall) qui appelle
  api.php en mode normal ou le stockage local en mode portable.
  Il n'y a donc pas deux projets a maintenir.

================================================================
 5) DEPANNAGE
================================================================

  "Erreur de connexion" au demarrage
      -> MySQL n'est pas demarre (XAMPP : bouton Start MySQL)
      -> verifiez hote/utilisateur/mot de passe dans db.php
      -> lancez Installer-Base.bat une premiere fois

  La page s'ouvre mais rien ne s'enregistre dans MySQL
      -> verifiez le badge en bas a droite : s'il est orange,
         l'application est en mode portable (serveur absent).
      -> utilisez Lancer-Version-Normale.bat plutot qu'un
         double-clic direct sur index.html.

  Le fichier portable n'existe pas / est ancien
      -> lancez build-portable.bat (Node.js requis)

  Port 8080 deja utilise
      -> inutile de faire quoi que ce soit : les lanceurs prennent
         automatiquement le premier port libre (8081, 8082...).
         L'adresse exacte est affichee dans la fenetre noire.
      -> si les 20 ports sont occupes, fermez les anciennes
         fenetres noires puis relancez le fichier .bat.

  Mot de passe oublie
      -> le mot de passe par defaut est admin2026.
      -> une fois connecte, changez-le dans le menu
         "Parametres" > "Securite - Modifier le mot de passe".
         Le nouveau mot de passe est enregistre dans MySQL en
         mode normal, et dans le navigateur en mode portable.
